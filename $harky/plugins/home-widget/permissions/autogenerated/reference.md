## Default Permission

Permite sincronizar el snapshot de datos del widget, refrescar los widgets, consultar diagnostico y pedir anclar un widget a la pantalla de inicio.

#### This default permission set includes the following:

- `allow-sync-snapshot`
- `allow-get-diagnostics`
- `allow-refresh-widgets`
- `allow-request-pin`
