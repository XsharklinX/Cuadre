## Default Permission

Permite sincronizar el snapshot de datos, programar/cancelar recordatorios locales (WorkManager) y gestionar el backup semanal automatico (elegir carpeta SAF, programar, probar y consultar estado).

#### This default permission set includes the following:

- `allow-sync-snapshot`
- `allow-schedule-reminders`
- `allow-cancel-reminders`
- `allow-sync-backup-snapshot`
- `allow-pick-backup-folder`
- `allow-schedule-weekly-backup`
- `allow-cancel-weekly-backup`
- `allow-run-backup-now`
- `allow-get-backup-status`
- `allow-set-system-bars`
- `allow-set-quick-add-notification`
- `allow-share-text`
- `allow-open-file`
- `allow-pick-image`
