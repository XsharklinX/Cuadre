## Default Permission

Permite verificar y abrir el acceso a notificaciones del sistema, y recibir eventos de notificaciones capturadas para detectar transacciones bancarias.

#### This default permission set includes the following:

- `allow-has-access`
- `allow-open-settings`
- `allow-register-listener`
- `allow-remove-listener`
- `allow-take-pending`
